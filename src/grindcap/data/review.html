Status read from the screen

Type a value to correct a misread; clear it to go back to what was read.

Slots hidden under a tooltip

These weren't counted. If one wasn't visible on another page either, say what it is (and the count), or ignore it.

Items that changed

Click a row to see the slots it was read from. Delete moves a misread item to the list below; to drop just one slot, use "Ignore this slot" there. Names and prices you set apply to every session; slot fixes apply to this session's snapshots only.

Deleted from this session

Not counted in this session. Restore puts an item back. Purge removes it for good: from your item list and its saved icons, so it isn't counted in any session.
